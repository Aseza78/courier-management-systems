# Project notes

## Project report summary

The submitted report describes a Courier Management System intended to coordinate a delivery from the customer's request through parcel delivery. It discusses customer and parcel details, pickup and destination addresses, payment records, driver assignment, delivery status updates, tracking, and returns.

## Entities listed in the report

Customer, Order, Package, Driver, Payment, Delivery, Tracking and Return.

## Normalisation

The report includes a normalisation table presenting the progression from UNF to 1NF, 2NF and 3NF. This repository does not claim an independent audit of every functional dependency or prove that the supplied schema is fully in 3NF.
